# House Price Prediction using Machine Learning

## Project Description
This project predicts house prices using Machine Learning and provides a Tkinter-based graphical user interface (GUI) for making predictions.

## Dataset
- Ames Housing Dataset

## Features Used
- Overall Qual
- Gr Liv Area
- Garage Cars

## Machine Learning Model
- Linear Regression

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Tkinter
- Pickle

## Project Files
- train_model.py
- tkinter_gui.py
- house_price_model.pkl
- AmesHousing.csv

## How to Run

1. Install the required libraries:
   ```
   pip install -r requirements.txt
   ```

2. Train the model:
   ```
   python train_model.py
   ```

3. Run the GUI:
   ```
   python tkinter_gui.py
   ```

## Output
The GUI accepts house details and predicts the estimated house price.
