# House Price Prediction using Machine Learning

## Project Description
This project predicts house prices using Machine Learning. A Linear Regression model is trained on the Ames Housing dataset and integrated with a Tkinter GUI for real-time price prediction.

## Dataset
- Ames Housing Dataset (Kaggle)

## Features Used
- Overall Qual
- Gr Liv Area
- Garage Cars

## Target
- SalePrice

## Machine Learning Model
- Linear Regression

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Tkinter
- Pickle

## Project Files
- AmesHousing.csv
- train_model.py
- tkinter_gui.py
- house_price_model.pkl
- requirements.txt

## How to Run

1. Install the required libraries:

```bash
pip install -r requirements.txt
```

2. Train the model:

```bash
python train_model.py
```

3. Run the GUI:

```bash
python tkinter_gui.py
```

## Output
Enter:
- Overall Quality
- Ground Living Area
- Garage Cars

Click **Predict Price** to see the estimated house price.
